# LX-AppStore

Official direct high-speed APK & XAPK download network with authentic version verification.

## 🚀 Live Link
[https://lxappstore.vercel.app/](https://lxappstore.vercel.app/)

## ✨ Key Features
- **Fluid Responsive Design**: Seamless pixel-by-pixel scaling across all devices from 325px up to 1920px (Mobile, Tablet, Laptop, and Desktop).
- **Search Ticker**: Dynamic marquee scrolling placeholder inside the search bar (exclusive to mobile views) with fixed search icons.
- **Custom Wishlist Modal**: Blur-effect app cards with trash-bin overlays, combined with a custom styled DOM confirmation dialog (eliminating the native browser popup prefix).
- **Dark & Light Themes**: Sleek pure black dark mode and bright blue active highlights.
- **Mobile Sidebar Menu**: Responsive slide-out navigation sidebar panel displaying Featured, Games, Apps, New Releases, and Categories.
- **Previous Versions Modal**: Grouped side-by-side action buttons for quick version selection and wishlist toggles.
- **Direct Downloads**: Direct high-speed download triggers for APK and XAPK files.
